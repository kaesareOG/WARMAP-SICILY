# Sicily RP — интерактивная карта

Это готовый MVP для вашего военного РП. Карта — присланное изображение Сицилии.

## Что уже умеет

- общая карта Сицилии по одной ссылке;
- игроки видят изменения почти в реальном времени;
- сектора рисуются прямо поверх карты;
- сектору задаётся владелец: Союзники / Ось / Спорный;
- сектора можно переименовывать и менять владельца;
- шаблонные военные объекты с иконками Font Awesome:
  - аэродром
  - порт
  - штаб
  - склад
  - артиллерия
  - укрепление
  - радар
  - мост
  - цель
- игроки ничего не редактируют без входа GM;
- история боёв НЕ хранится.

## Быстрый запуск

### 1. Supabase

Создай бесплатный проект в Supabase.

В SQL Editor вставь весь файл `supabase.sql` и нажми Run.

В Authentication → Users создай аккаунт GM (email + пароль).

### 2. Подключение

В Supabase открой Project Settings → API.

Скопируй:
- Project URL
- anon public key

Открой `index.html` и замени:

PASTE_YOUR_SUPABASE_URL
PASTE_YOUR_SUPABASE_ANON_KEY

на свои значения.

### 3. Публикация по ссылке

Самый простой вариант — Vercel.

Создай аккаунт, импортируй эту папку как проект и опубликуй её. Либо загрузи проект в GitHub и подключи репозиторий к Vercel.

После публикации получится одна постоянная ссылка вида:
https://твой-проект.vercel.app

Её можно просто дать всем игрокам.

## Важное про безопасность

В текущем MVP любой пользователь, которому ты выдашь GM-аккаунт, сможет редактировать карту. Обычные игроки без авторизации имеют только чтение.

Если хочешь строго одного администратора, следующий апгрейд — отдельная таблица `admins` + RLS, чтобы только твой аккаунт мог создавать/изменять/удалять объекты и сектора.

## Что логично сделать следующим

1. Не использовать prompt-окна, а сделать красивую GM-панель.
2. Рисовать сектор мышкой и сразу открывать нормальную форму:
   название / сторона / гарнизон / цвет / заметки.
3. Сделать перетаскивание объектов.
4. Сделать редактирование геометрии уже нарисованных секторов.
5. Добавить удаление сектора/объекта.
6. Сделать собственные военные символы вместо Font Awesome.
7. Добавить названия населённых пунктов и сетку.
8. Сделать мобильный интерфейс.
